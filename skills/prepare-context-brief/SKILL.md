# prepare-context-brief

Recall the project and scope using the existing authorized tools. Keep source IDs, dates, labels and uncertainty. Fetch full entries only when missing context matters. Prefer active canonical decisions over superseded notes, but retain historical distinctions. Use the original response and its warnings. Do not infer access from a project slug alone. Return a small manifest of references and observations. Share selected context with the next chat only after the user selects it.
