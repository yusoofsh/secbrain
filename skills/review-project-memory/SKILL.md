# review-project-memory

Use review_project_memory or recall with an explicit project or subject and authorized workspace. Get the full selected entry before relying on a truncated preview. Distinguish observed facts, historical decisions and tentative suggestions. Cite original IDs and capture time. Surface possible duplicate or contradictory entries as candidates, not established errors. Propose a change separately. Never overwrite, delete, change status or share a memory without explicit user approval of the exact operation. Re-read the entry and its access permissions immediately before a separately approved write.
